## Findings (the actual point of G3)

1. **Honest failure works.** Run 1 died mid-turn: the gateway timed out
   reading the response after 5 successful exploration tool calls, and the
   retry budget ended the turn `cancelled` (7 steps, 2,147 tokens) — no
   fabricated success, exactly the governor contract from M1.
2. **Gateway flakiness is the top friction.** Run 2 (identical command)
   completed (16 steps, 15,043 tokens). A dogfooding week needs
   per-request timeout tuning (`timeout_secs` is 120 today) and possibly a
   smaller per-turn ask; both are real product feedback.
3. **Exploration wander.** The model made ~10 exploratory list/read calls
   (some repeated) before writing. Tool-result brevity and a nudge
   governor (already in agent-core) are the levers; measure again on day 2.
4. **The seam held.** No double-executed tools, kernel session written,
   NDJSON stream clean — the M1 invariants survived first contact with a
   live model doing a non-bench task.

## Session 2 (same day, 2026-09-28 morning) — harness evolution driven by day-1 findings

Task: extend dogfood-log.sh with `--stream <file>` (the day-1 snapshot idea),
with backward compatibility and graceful missing-stream handling. Run:
completed, 25 steps, 27,736 tokens, 34 tool calls.

Findings:

1. **The workspace sandbox caught a task-author mistake.** The prompt asked
   the model to test with a stream file under `/tmp`; the model complied and
   the write was REFUSED — "path escapes the workspace". The safety contract
   did exactly its job against the human's own sloppy spec. (Lesson: task
   prompts must respect the workspace boundary.)
2. **write_file does not preserve the exec bit on overwrite.** The rewritten
   dogfood-log.sh lost `+x` and the acceptance run failed with permission
   denied until a manual chmod. Product item: mode preservation (or an
   explicit `executable` field) on overwrite.
3. **Cosmetic: `wc -l` padding leaks into the journal line** — `(       2
   lines)` instead of `(2 lines)`. Trivial, but exactly the kind of thing a
   review pass catches.
4. **Exploration wander again** (~20 reads/lists before the write, several
   repeats). Consistent with day 1; the nudge-governor lever stands.
5. All three forms acceptance-tested for real: stream copy + journal line,
   legacy form, and graceful `stream: missing (<path>)` on a nonexistent
   file (exit 0).

## Session 3 (2026-09-28, readiness probe for day 2) — `--version` gap fixed

Preparing the scheduled automation surfaced a real product gap: okra had NO
`--version` flag, so the harness's version probe (`okra --version`) would
have run an ENTIRE agent turn and captured its output as the version string
whenever okra is on PATH. Fixed in the CLI: `--version`/`-V` print and exit
before any prompt handling. Verified end-to-end: the harness journal now
records `version: okra 0.1.0` instead of the fallback.

Dogfood loop status: 3 sessions on day 1, each finding feeding the next
action — the loop the M3 gate is meant to institutionalize.
